ACEhole

ACE Asheron's Call Server Manager — User Guide — Version 0.0.2

Overview

ACEhole is a Windows desktop application for managing and supervising a locally-hosted ACE (Asheron's Call Emulator) server. It replaces the manual batch-file restart loop with a protected GUI that launches ACE.Server.exe, monitors it, and auto-restarts it on crash — all in a single window that protects the server from accidental closes.

ACE is a headless console application with no graphical interface. A single mis-aimed click can terminate the server process. ACEhole solves this by running the server inside a protected host process and displaying its output in a readable, color-coded console.

Quick Start

  1. Open View → Settings → Server Settings
  2. On the Paths sub-tab, verify:
    • ACE Executable — path to ACE.Server.exe
    • Log File Path — path to the ACE server log file
  3. Click ▶ Start Server
  4. The Server Console tab shows all output. The status bar updates with process metrics.
ACEhole tails the ACE log file for console output rather than redirecting stdout. The log file location is set in ACE's log4net.config file in the server directory. The default path configured in ACEhole is Z:\ACE TEST\Logs\FULL\ACE_Log.txt. Update this in Settings if your log file is in a different location.

Server Console Tab

The main tab shows live output from ACE.Server.exe, color-coded by message type:

  • Joins/Leaves — player connection events (green)
  • Chat — global chat messages (cyan)
  • Errors — server errors and exceptions (red)
  • Warnings — server warnings (orange)
  • MODs — mod system messages (purple)
  • Saves — server save operations (teal)
  • Default — all other output (gray)

Console Commands

The Console Commands bar sends commands to the server via stdin. Type a command and press Enter. The last 20 commands are saved in the dropdown for quick reuse. The history size is configurable in Settings → UI Settings → General.

Global Chat

The Global Chat bar sends a broadcast message to all players. The chat command format will be confirmed once ACE console command documentation is available. Chat history (last 20) is persisted across sessions.

Repeated Line Suppression

Consecutive identical lines (e.g., repeated connection errors) are collapsed into a single suppression notice showing the count. This keeps the console readable during network storms. Toggle in Settings → UI Settings → General → Suppress repeated console lines.

Status Bar

Always visible at the bottom of the window across all tabs:

  • Row 1: Players Online
  • Row 2: State · Uptime · Memory — version right-aligned

Values are green when populated, orange when zero, gray when server is stopped.

Settings Dialog

Open via View → Settings. The dialog is modeless — the main window remains usable while Settings is open. Position is remembered between sessions.

UI Settings — General

  • Theme — Light / Dark / System (follows Windows setting)
  • 24-hour time format — toggle 12/24 hour in timestamps
  • Minimize to tray on close — when server is running, shows a Hide/Stop/Cancel prompt instead of exiting
  • Auto-refresh Server Status — refresh interval in seconds
  • Suppress repeated console lines — collapse flood messages
  • Export/Import Config — backup and restore all settings
  • Command/Chat history size — max entries to persist per dropdown

UI Settings — Windows

Per-window always-on-top and show-in-taskbar toggles for Main Window, Log Viewer, and Settings. Position reset buttons to return each window to its default position.

Logs — Log Files

  • Max log file size — rotate when file exceeds this size (MB)
  • Log files to retain — keep this many files per log type
  • Enable debug logging — write DEBUG entries to the App log
  • Auto-delete old log files — enforce the retention limit on startup

Logs — Log Colors

Click any color swatch to open a color picker. Changes apply immediately to new console output. Separate toggles for console output and Log Viewer. Reset to Defaults restores all colors to the factory values.

Notifications — Tray

  • Enable tray notifications — master toggle for balloon notifications
  • Show notification on server start/stop

Notifications — Sound

  • Play sound on server start — plays server_start.wav
  • Play sound on server stop — plays server_stop.wav

Log Viewer

Open via View → Log Files or the Log Files toolbar button. A floating window that shows Application and Console logs:

  • Navigate dates with ◄ ► buttons
  • Switch between Application log (color-coded by INFO/WARN/ERROR/DEBUG) and Console log (color-coded by message type)
  • Live tail: today's log updates in real time
  • Smart auto-scroll: follows new output unless you scroll up
  • Save Log and Delete Log buttons

System Tray

  • Minimize to tray when server is running (configured in Settings)
  • Double-click tray icon to restore the window
  • Right-click for context menu: Open / Exit
